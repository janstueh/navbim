# navbim_rviz_plugins

The `navbim_rviz_plugins` package provides RViz 2 panel plugins for visualizing and interacting with BIM models and the navbim topological map during robot operation.

## Plugins

### BimPanel

An RViz panel for intuitive BIM-based path planning and building visualization.

- Allows floor selection; once a floor is selected, the meshes of all `IfcBuiltElement` elements on that floor are loaded and displayed as `visualization_msgs/Marker` mesh resources.
- Enables setting start and goal poses by placing arrows directly on the BIM mesh surfaces.
- Triggers path planning automatically when a goal pose is set, calling `navbim_gpp_bim` to plan a path from the current start pose to the goal.
- Visualizes the pruned topological map used during planning.

The per-element meshes are generated by `navbim_nav_model_gen` using the `IfcConvert` tool from IfcOpenShell during navigation model generation.

### TopomapPanel

An RViz panel for monitoring and interacting with the topological map of the building.

- Displays the current state of the topological graph (nodes and edges).
- Shows the currently active room as reported by `navbim_room_tracker`.
- Allows manual triggering of room-level navigation goals.

## Plugin Registration

Plugins are registered in `plugins_description.xml` and loaded by RViz 2 via `pluginlib`.

## Usage

The RViz plugins are loaded automatically when using the navbim RViz configuration:

```bash
ros2 launch navbim_bringup rviz_launch.py
```

To add a plugin manually in RViz, use **Panels → Add New Panel** and select the desired navbim panel from the list.

## Related Packages

- `navbim_bim_server`: provides the IFC element query services used by `BimPanel`
- `navbim_room_tracker`: provides the current room information displayed by `TopomapPanel`
- `navbim_topomap_server`: provides the topological map displayed by `TopomapPanel`
